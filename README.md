#  Introduction to Data Visualization in Stata
# Presented and Prepared by O. Kuester 

This repository contains example data and Stata code for the Introduction to Data Visualization in Stata workshop hosted by the University of Iowa's Center for Social Science Innovation (CSSI) on October 21st, 2026.

## Workshop Overview

This workshop introduces basic principles of data visualization and demonstrates how to create and customize three common forms of data visualization in Stata:

* **Bar charts:** Comparing values across categories.
* **Scatterplots:** Examining relationships between two quantitative variables.
* **Histograms:** Visualizing the distribution of a quantitative variable.

## Data

The workshop uses the well-known Iris dataset, which contains measurements from three species of iris flowers. The data were collected by Fisher (1936) and include measurements of sepal length, sepal width, petal length, and petal width.

For more information about the dataset, see the [UCI Machine Learning Repository: Iris Dataset](https://archive.ics.uci.edu/dataset/53/iris).

## Repository Contents

This repository contains the workshop slides, the Iris dataset and Stata do-files used for workshop demonstrations and hands-on exercises.

* Stata

## Getting Started

You can run the workshop code using your own installation of Stata or through the University of Iowa's virtual desktop.

1. **Access Stata.** Open Stata on your own computer if you have it installed. Otherwise, log in to the [University of Iowa Virtual Desktop](https://its.uiowa.edu/services/virtual-desktop) and open Stata there.

2. **Download the workshop do-files.** Download the `.do` files from this repository to your computer. If you are using the virtual desktop, you may need to upload the files to the virtual environment before opening them in Stata.

3. **Follow Along During the Workshop.** Open the unfilled do-file in Stata's Do-file Editor to follow the demonstrations and complete the code yourself.

4. **Keep the Filled-In Version for Reference.** The filled-in do-file contains the completed workshop code. Save it for future reference when practicing or creating your own visualizations.

**Note:** You do not need to download the Iris dataset separately. The do-files import the data directly from this repository, so an active internet connection is required to run the data import command.
