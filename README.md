#  Introduction to Data Visualization in Stata
# Presented and Prepared by O. Kuester 

This repository contains example data and Stata code for the Introduction to Data Visualization in Stata workshop hosted by the University of Iowa's Center for Social Science Innovation (CSSI) in 2026.

## Workshop Overview

This workshop introduces basic principles of data visualization and demonstrates how to create and customize three common forms of data visualization in Stata:

* **Bar charts:** Comparing values across categories.
* **Scatterplots:** Examining relationships between two quantitative variables.
* **Histograms:** Visualizing the distribution of a quantitative variable.

## Data

The workshop uses the well-known Iris dataset, which contains measurements from three species of iris flowers. The data were collected by Fisher (1936) and include measurements of sepal length, sepal width, petal length, and petal width.

For more information about the dataset, see the [UCI Machine Learning Repository: Iris Dataset](https://archive.ics.uci.edu/dataset/53/iris).

## Repository Contents

This repository contains the Iris dataset and Stata do-files used for workshop demonstrations and hands-on exercises.

## Requirements

* Stata
* The do-files provided in this repository. 

## Getting Started

1. Download the do-files from this repository.
2. Open the do-files in Stata.
3. **Note:** You do not need to download the Iris dataset separately. The do-files import the data directly from this GitHub repository, so only an internet connection is required to run the import command.
